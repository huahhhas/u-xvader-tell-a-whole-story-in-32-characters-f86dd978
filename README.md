# Tell a Whole Story in 32 Characters

A make.fun bounty entry: one Wi-Fi network name of at most 32 characters that
lands a joke and implies a whole story.

## The entry

> **Mom's WiFi, Dad's new girlfriend**

32 characters. The divorce in one network name: Mum kept the router, Dad moved
on, and the Wi-Fi list is where the whole family story now lives.

## Run

```sh
python3 main.py
```

Prints exactly the entry above, nothing else.
